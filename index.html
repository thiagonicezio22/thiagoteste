📋 Referência — capacidade do tubo por diâmetro

Vazão máxima aproximada por velocidade (Q = velocidade × área). ABNT: recalque 0,6–2,0 m/s; máx. 3,5 m/s.

Pelo diâmetro NOMINAL (prática de mercado). Ex.: 50 mm a ~3,7 m/s ≈ 26.000 L/h. Para precisão use o DI real no cálculo.

📐 Base de engenharia

  • Curva do sistema: H(Q) = desnível + pressão exigida + perdas.
  • Perda no tubo (Hazen-Williams): J = 10,643·Q1,852·C−1,852·D−4,87 (Q m³/s, D m); hf=J·L.
  • Perda nas conexões (coef. K): hloc = ΣK·V²/(2g), V=Q/Área, g=9,81.
  • Ponto de operação: Q onde curva da bomba = curva do sistema (bisseção).
  • NPSH disp. = Patm − Pvapor − altura sucção − perdas sucção; ≥ NPSHr + 0,6 m.
